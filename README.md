# Milliy Mahalliy Tovuq — demo website

Files:
- `index.html` — HTML structure
- `style.css` — styling
- `script.js` — product/admin logic

## Local preview
Open `index.html` in a browser.

## Deploy to Vercel (static)
Upload these files to a GitHub repository root, then import the repository in Vercel.
Framework preset: Other. Build command: leave blank. Output directory: `.` (root).

## Admin
Click Admin in the footer. Demo password: `demo`.
Product edits, logo, phone, and site title are saved in the browser's local storage for this demo.
This is not shared between browsers/devices and is not secure production authentication.
Orders are by phone only; no cart or online checkout.
